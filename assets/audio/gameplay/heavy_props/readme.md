# Перенос тяжёлых предметов

Оригинальные звуки подготовлены офлайн через `tools/authoring/author_heavy_prop_audio.py` из периодического фильтрованного шума и затухающих резонансов. Сторонние записи не использованы. Mono PCM16, 32 kHz; пиковый уровень ограничен, постоянная составляющая убрана. В runtime воспроизводятся готовые ресурсы Godot.

`bench`, `sofa`, `concrete`: для каждого `drag` — непрерывная четырёхсекундная петля, `lift` — короткое усилие/скрип, `place` — контакт с поверхностью. У drag в импорте включён Forward Loop; у остальных зацикливания нет. После первого импорта при повторной подготовке инструмент сохраняет настройку петли.

Подключение: `scenes/objects/props/heavy_prop_audio.tscn`; конкретные клипы, громкость и радиусы заданы в игровых сценах предметов. Подробности — `docs/technical/audio_mix.md`.
