# HUD typography

Roboto Condensed is embedded in the game, including Cyrillic. Source: the official Google Fonts repository, `ofl/robotocondensed/RobotoCondensed[wght].ttf`.

https://github.com/google/fonts/tree/main/ofl/robotocondensed

The original SIL Open Font License is included in `OFL.txt`. `body.tres` uses weight 450; `heading.tres` uses weight 600 and additional letter spacing. Import uses 4× oversampled rasterization with mipmaps. This preserves the original contours at joins (MSDF produced small holes in variable-font numerals). The original font file is unmodified.
