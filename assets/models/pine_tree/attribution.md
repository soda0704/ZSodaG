This work is based on "Pine tree" (https://sketchfab.com/3d-models/pine-tree-e52769d653cd4e52a4acff3041961e65) by Andriy Shekh (https://sketchfab.com/sheh5262), licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

Commercial use is permitted under that license. Attribution is still required for the adapted model; alterations do not remove that requirement.

Changes for NorthernLab: normalized scale/orientation and combined mesh surfaces for the existing MultiMesh forest; generated native Godot mesh LODs; changed foliage to alpha cutout, increased material roughness and applied a slight cool foliage tint. The source geometry and original license are preserved.

The adapted mesh has a height of one unit. Saved tree transforms restore the original tree heights, root positions and trunk collisions. Only the playable Landscape trees were replaced. Distant scenery billboards remain in CliffValley.
