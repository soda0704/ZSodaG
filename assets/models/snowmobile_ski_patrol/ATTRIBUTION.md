# Ski Patrol Snowmobile

This work is based on "Ski Patrol Snowmobile MEDPOLY" (https://sketchfab.com/3d-models/ski-patrol-snowmobile-medpoly-96eca5d1835441f39eae83cb67f80529) by EvanLegrand (https://sketchfab.com/evan4129), licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

Modified for NorthernLab: native Godot scene, corrected orientation and scale, track geometry simplified with Godot meshoptimizer; 33,788 to 30,976 triangles (8.32% reduction). Body, skis, mirrors, windshield and handlebar base geometry retained. Native distance LODs generated. Original license.txt retained.
