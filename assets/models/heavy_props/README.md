# Тяжёлые предметы

Подготовленные модели для сцен `scenes/objects/props` и верстака сборки огнемёта.

| Модель | Исходные треугольники | Подготовлено |
| --- | ---: | ---: |
| Балка 1 | 175872 | 12239 |
| Балка 2 | 160056 | 18869 |
| Диван | 9648 | 3376 |
| Скамья | 568 | 568 |
| Верстак | 742 | 742 |

Скамья и верстак уже достаточно простые; дальнейшее упрощение портило бы форму. Оба варианта балки сохранены, на −1 этаже используется первый. Общие текстуры не дублируются между вариантами. Сведения о присланных моделях сохранены в `joists_source.json` и `workbench_source.json`, измерения — в `preparation.json`.

Подготовка: `tools/authoring/prepare_heavy_props.py` через Blender; затем импорт Godot и `tools/authoring/author_heavy_prop_scenes.gd`. Исходники дивана и скамьи остаются в `Blender/East_Living/CommonRoom`. Эти инструменты нужны для повторной подготовки исходников, а не для обычного редактирования сцен.

У первой балки удалён отдельный кусок арматуры на 1,03–1,15 м ниже бетона: 60 треугольников. Бетон, прикреплённая арматура, UV и материалы сохранены; второй вариант не изменён. `remove_joist_stray_rebar.py` делает эту точечную очистку подготовленного glTF и входит в повторную подготовку моделей. Физическая выпуклая коллизия бетонного ядра не менялась.
