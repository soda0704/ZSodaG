# Kitchen Knife replacement

Kitchen Knife by Bornx: https://sketchfab.com/3d-models/kitchen-knife-1d91ba79869d4370948f71c10cc17ab7

The user-supplied source archive declares the Sketchfab Standard license. Its original notice is retained in `license.txt`. This asset is not CC BY. The game keeps the existing `kitchen_knife` item ID, damage and attack timing.

Adaptations: 30 cm total length, blade facing Godot -Z, source handle centre as the visual origin, preserved base colour / metallic-roughness / normal textures, four separately named material parts. `tools/authoring/import_kitchen_knife.py` reproduces the GLB replacement from this preserved source directory.
