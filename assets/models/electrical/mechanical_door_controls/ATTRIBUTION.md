# Mechanical Door Controls

Source: [Mechanical Door Controls](https://sketchfab.com/3d-models/mechanical-door-controls-7e861c772c254421a2c8ae50d533cb1a) by [d880](https://sketchfab.com/distance880), CC BY-NC 4.0, as supplied in the user archive. Original license is preserved in `license.txt`.

The assembled model is used. Offline authoring separates the original handle stem and upper crossbar, retaining the fixed lower bearing for native AnimationPlayer movement and rotates/scales the original geometry for the breaker scene. The original housing, textures, UV layout and source files are preserved. Cable meshes are authored separately for the maintenance interaction.

License documents are asset metadata, not project instructions.
