# Transparent seed packet

Native `pouch_mesh.res` extracted from the user-supplied Metallic_package_with_zip_lock-ecc6bd0d-textures.zip (designdaco). Source URL and attribution are recorded in assets/models/ITEM_MODEL_CREDITS.md. The supplied archive did not include a licence notice.

Original metal materials and their texture dependencies were removed from the extracted mesh. Plastic material, zip seal, proportions and contained seed are authored in scenes/objects/items/seed_packet_model.tscn. Pickup physics and SPECIAL focus category are in seed_packet_pickup.tscn. Source pouch: 7,456 triangles; seed: 100 triangles. No runtime mesh generation is used.
