# NorthernLab — запуск после Git

GodotSteam является частью проекта. После `pull` в `addons/godotsteam/win64/`
должны находиться:

- `libgodotsteam.windows.template_debug.x86_64.dll`;
- `libgodotsteam.windows.template_release.x86_64.dll`;
- `steam_api64.dll`.

## Первый запуск на Windows

1. Закройте Godot.
2. Запустите `SETUP_NORTHERNLAB.cmd` в корне проекта.
3. Скрипт подготовит изолированный редактор в `tools/.local/`, соберёт
   отладочный `build/dev/NorthernLab.exe` и создаст ярлыки.
4. `NorthernLab.lnk` запускает игру напрямую.
5. `NorthernLab - Editor.lnk` открывает проект для разработки.

Отладочный EXE — не релизная и не «замороженная» версия игры. Это обычный
development export с включённой отладочной информацией. После изменений запустите
`BUILD_NORTHERNLAB_DEV.cmd`: EXE пересоберётся из текущих файлов проекта, а ярлык
останется прежним. Папка `build/`, локальный редактор и `.lnk` исключены из Git.

EXE начинает игру в единственной тестовой сцене с вертолётным лобби и комнатой
механик. После восстановления питания и открытия двери терминал переводит всю
текущую Steam-сессию в `Base_Blockout_v03`.

Не запускайте проект кнопкой запуска Steam-версии Godot: рядом с ней может лежать
другая `steam_api64.dll`, из-за чего Windows возвращает `Error 127`.

## Steam Overlay и совместный тест

Для проверки Overlay добавьте в Steam как стороннюю игру именно
`build/dev/NorthernLab.exe` и запускайте его из библиотеки Steam. Тогда Steam
подключается к графическому процессу игры до создания окна; `Shift+Tab` и кнопка
приглашения могут работать корректно.

Пока используется тестовый App ID `480`, Steam показывает SpaceWar. У этого режима
есть ограничение: приглашение надёжно подключает друга, уже запустившего NorthernLab,
но не умеет автоматически запустить именно ваш EXE на другом компьютере. Для полного
invite-flow из библиотеки нужен собственный Steamworks App ID и Steam Playtest/depot.
До этого используйте приглашение при уже открытой игре или Lobby ID.

## Управление

- `WASD` — движение;
- `Shift` — бег;
- `Ctrl` — приседание;
- `Space` — прыжок;
- `E` — взаимодействие;
- `F` — фонарик / удар по неисправному фонарику;
- `G` — выбросить текущий предмет;
- `Esc` — меню без локальной остановки сетевого мира.
