# NorthernLab — первый запуск после Git

GodotSteam является частью проекта и должен скачиваться вместе с репозиторием. После `pull` в папке `addons/godotsteam/win64/` должны находиться:

- `libgodotsteam.windows.template_debug.x86_64.dll`;
- `libgodotsteam.windows.template_release.x86_64.dll`;
- `steam_api64.dll`.

## Windows и Godot из Steam

Не открывайте проект напрямую кнопкой запуска Steam-версии Godot. В её папке может находиться другая версия `steam_api64.dll`, из-за чего загрузчик Windows возвращает `Error 127`.

Первый запуск:

1. Закройте открытый редактор Godot.
2. Дважды нажмите `SETUP_NORTHERNLAB.cmd` в корне проекта.
3. Скрипт подготовит локальную совместимую копию редактора в `tools/.local/`.
4. В корне появятся `NorthernLab.lnk` для игры и `NorthernLab - Editor.lnk` для редактора.
5. В дальнейшем запускайте проект только этими ярлыками.

Локальная копия редактора и созданные `.lnk` специально исключены из Git: пути к ним индивидуальны для каждого компьютера. Установщик не изменяет файлы Godot внутри Steam.

Если установщик сообщает, что GodotSteam неполный, выполните `git pull` и убедитесь, что автор коммита добавил в Git всю папку `addons/godotsteam/`, включая DLL-файлы.

Подробности сетевого прототипа находятся в `docs/technical/steam_networking.md`.
