# NorthernLab — разработка и запуск

Актуальная сводка на **15 сентября 2026**: [состояние проекта и карта документации](docs/PROJECT_STATUS.md).
Правила передачи моделей и текстур: [art pipeline](docs/technical/art_pipeline.md).

GodotSteam является частью проекта. После `pull` в `addons/godotsteam/win64/`
должны находиться:

- `libgodotsteam.windows.template_debug.x86_64.dll`;
- `libgodotsteam.windows.template_release.x86_64.dll`;
- `steam_api64.dll`.

4K-видеофон хранится через Git LFS. Лаунчер сам распознаёт LFS pointer и перед
сборкой выполняет локальные `git lfs install` и `git lfs pull`. На компьютере
должны быть установлены Git for Windows и Git LFS, а проект нужно получать через
`git clone`, не через ZIP-архив GitHub.

## Сборка и запуск на Windows

1. Для разработки открывайте проект обычным способом из списка проектов Godot.
2. Для сборки и запуска игры откройте `NorthernLab.cmd`.
3. Лаунчер автоматически проверит GodotSteam, пересоберёт актуальный development
   EXE и обновит единственный ярлык `NorthernLab.lnk`.
4. Выберите режим окна, разрешение, монитор и VSync, затем нажмите `Играть`.

Готовая сборка находится в `build/windows-dev/NorthernLab.exe`. Отладочный EXE —
не релизная и не «замороженная» версия игры: он каждый раз пересобирается из
текущих файлов проекта. Настройки лаунчера хранятся в локальном профиле Windows,
поэтому папка `build/` содержит только актуальную сборку.

EXE начинает игру в отдельном главном меню. Одиночный режим сразу загружает базу V3,
без старой комнаты механик. Steam-режимы позволяют создать лобби или подключиться
по Lobby ID. Отдельная пустая тестовая комната доступна через `/testroom`.

`Продолжить` загружает сохранённую базу сразу, без повторения тестовой комнаты.
Начиная с Day 2 игрок появляется у своей койки. Одиночный и кооп-checkpoint
хранятся отдельно; при создании лобби можно продолжить кооп или подтвердить новую
экспедицию. Продолжение коопа после готовности участников ведёт из вертолёта в V3.

Day 2: получите задание у терминала центрального хаба, извлеките ключ из терминала
хранилища данных на 1 и сдайте его в хабе. Ключ занимает общий сюжетный слот,
не вытесняет фонарик и сохраняется при disconnect и загрузке checkpoint.
До сдачи ключа завершить второй день нельзя. На третьем дне доступны обследование
уровней 2 и 3, бой с существами и устранение сбоя света через главный щит.
После первой ночи также требуется восстановить проводку в генераторной.

Лаунчер генерирует отпечаток скриптов, сцен и настроек; несовместимая сборка
отклоняется при подключении. Перед ручным export выполните:
`godot --headless --path . --script tools/write_build_identity.gd`.

Главное меню использует зацикленный видеофон со звуком. Настройки разрешения,
режима окна, монитора, VSync, общей громкости, отдельной громкости музыки и
чувствительности мыши доступны как из главного меню, так и через `Esc` во время
игры. Выход из одиночной или Steam-сессии всегда возвращает в главное меню;
закрытие приложения выполняется отдельной кнопкой главного меню.

Не запускайте проект кнопкой запуска Steam-версии Godot: рядом с ней может лежать
другая `steam_api64.dll`, из-за чего Windows возвращает `Error 127`.

## Steam Overlay и совместный тест

Для проверки Overlay добавьте в Steam как стороннюю игру именно
`build/windows-dev/NorthernLab.exe` и запускайте его из библиотеки Steam. Тогда Steam
подключается к графическому процессу игры до создания окна; `Shift+Tab` и кнопка
приглашения могут работать корректно.

Пока используется тестовый App ID `480`, Steam показывает SpaceWar. У этого режима
есть ограничение: приглашение надёжно подключает друга, уже запустившего NorthernLab,
но не умеет автоматически запустить именно ваш EXE на другом компьютере. Для полного
invite-flow из библиотеки нужен собственный Steamworks App ID и Steam Playtest/depot.
До этого используйте приглашение при уже открытой игре или Lobby ID.

## Управление

В гараже доступен [снегоход и совместное открытие ворот](docs/technical/garage_snowmobile.md).
С канистрой в руках E заправляет снегоход; без канистры E позволяет сесть.
WASD — езда, E — слезть. Два игрока удерживают E у разных оранжевых рукоятей
ворот, пока они не поднимутся.

Прямой запуск `Base_Blockout_v03.tscn` через F6 — временный тестовый сеанс:
он начинается с настроенного стартового дня и не читает, не записывает и не
удаляет обычный checkpoint. Для проверки сохранений запускайте игру через
главное меню. Автотесты могут явно назначить отдельный путь через
`northern_lab/testing/base_save_path`; этот путь должен отличаться от игровых.

- `WASD` — движение;
- `Shift` — бег;
- `Ctrl` — приседание;
- `Space` — прыжок;
- `E` — взаимодействие; на предмете короткое нажатие подбирает его,
  удержание позволяет таскать с занятыми руками, отпускание бросает;
- `F` — достать и включить / убрать и выключить фонарик;
- `R` — перезарядка оружия / контекстная замена разряженной батарейки;
- `G` — выбросить текущий предмет;
- `J` — открыть или убрать общий журнал заданий;
- `~` / `ё` — консоль разработчика; `/help` — команды, `/outside` — улица,
  `/level 0` — обратно на базу; `/testroom` — тестовая комната/возврат;
- `Esc` — убрать открытый журнал, иначе открыть меню без локальной остановки сетевого мира.

Подробности сети: `docs/technical/steam_networking.md`.
Консоль, команды по прицелу, Tab и цепочки через `;`: `docs/technical/developer_console.md`.
Предметы, батарейки и генератор: `docs/technical/item_system.md`.
Day 2, checkpoints и тесты: `docs/technical/day_two_slice.md`.

Журнал также показывает квест-предметы команды, личный фонарик и запас батареек;
в нём доступны замена и выбрасывание снаряжения. Канистра/предохранитель убирают
фонарик в карман, не выбрасывая его. Инвентарь и оставленные предметы V3 входят
в checkpoint. Подробности: `docs/technical/equipment_inventory.md`.

DualSense: `□` — взаимодействие, `×` — прыжок, `○` — переключить приседание,
нажатие `L3` — бег до остановки, `△` — достать/убрать фонарик,
крестовина `↑` — заменить батарейку, `↓` — бросить предмет из рук,
`Touchpad / Create` — журнал, `Options` — меню. Подсказки переключаются по
последнему использованному устройству; раскладка видна и в журнале.
