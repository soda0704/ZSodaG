# NorthernLab

NorthernLab — игра от первого лица об экспедиции на изолированную снежную базу и исследовании подземного комплекса. Доступны одиночная игра и кооператив на двух игроков. Проект находится в разработке.

## Начало работы

1. Получите проект через `git clone`; для видео и HDR-ресурсов установите Git LFS и выполните `git lfs pull`.
2. Откройте `project.godot` в совместимом Godot. Проект использует Forward+, Jolt Physics, GodotSteam и Terrain3D.
3. Для Windows-сборки запустите `NorthernLab.cmd`. Лаунчер проверит зависимости, соберёт игру и откроет настройки запуска.
4. Новая игра начинается в вертолёте. Через `Esc` подтвердите готовность к посадке. Сохранённая экспедиция запускается кнопкой «Продолжить».

Сборка: `build/windows-dev/NorthernLab.exe`. Для проверки Steam Overlay запускайте этот EXE из библиотеки Steam. Локальная связка редактора и Steamworks находится в `tools/.local/godotsteam-editor/`; её подготавливает лаунчер.

## Структура репозитория

| Каталог | Назначение |
| --- | --- |
| `scenes/levels` | База, подземные уровни и наружная территория |
| `scenes/art` | Оформление и модели в сценах |
| `scenes/objects`, `scenes/characters`, `scenes/ui` | Объекты, персонажи и интерфейс |
| `scripts` | Игровая логика, сеть, эффекты и интерфейс |
| `assets` | Модели, текстуры, звук, шрифты и настройки |
| `Blender` | Авторские исходники; автоматический импорт отключён |
| `tools` | Сборка, подготовка ресурсов и проверки |
| `docs` | Документация проекта |

`.godot/`, `build/` и `tools/.local/` — локальные данные. Они не включаются в Git. Файлы `.uid` и `.import`, используемые сцены, лицензии и атрибуции необходимо сохранять.
