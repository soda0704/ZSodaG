# Modular SciFi MegaKit — полная библиотека объектов

Все **191 уникальная модель** из архива Quaternius подготовлены как отдельные
сцены Godot. Ещё **17 вариантов потолка** сделаны из плоских панелей пола.
Добавлена **1 половинка пола**: `PlatformXHalf`. Итого: **209 объектов**.
Игровые уровни при подготовке библиотеки не изменяются.

| Папка | Содержимое | Сцен |
|---|---|---:|
| `walls` | Прямые, угловые и закруглённые стены, верхние и нижние секции | 84 |
| `floors` | Платформы, лестницы, пандусы и решётки | 32 |
| `ceilings` | Перевёрнутые плоские панели | 17 |
| `doors` | Дверные рамы и полотна | 7 |
| `columns` | Колонны | 8 |
| `props` | Предметы, оборудование и отдельная крыльчатка вентилятора | 29 |
| `decals` | Плоская разметка и символы | 29 |
| `aliens` | Три существа с анимацией | 3 |
| `catalogs` | Восемь обзорных сцен по категориям | — |

## Как использовать

1. Найди нужную папку в **FileSystem** Godot и перетащи отдельный `.tscn`
   в дерево своей сцены или в 3D-окно. Материалы и текстуры уже подключены.
2. Для просмотра всего раздела открой соответствующую сцену из `catalogs`.
   Это обзорная раскладка для редактора, без игровой камеры.
3. Масштаб, UV и исходные точки привязки моделей сохранены. Начинай с масштаба
   **(1, 1, 1)**, поворотов по 90° и привязки перемещения к сетке.
   Размеры разных деталей отличаются; не растягивай угловые элементы, чтобы
   подгонять их к прямым. Исходные стены ориентированы лицевой стороной по +X,
   дверные полотна — по +Z. Для коротких и верхних секций сохранена исходная
   высота относительно точки привязки всего модуля.
4. У потолочных вариантов лицевая сторона направлена вниз, нижняя поверхность
   находится на **Y=0**, толщина панели уходит вверх. Поставь корень сцены
   на требуемую высоту потолка.
5. Декали — геометрические плоскости. Размещай их с небольшим отступом
   от стены или пола, чтобы поверхности не мерцали.

Обычные неподвижные объекты имеют точные статические коллизии на слое 1.
Они подходят для стен, лестниц и окружения. Дверные полотна здесь также
статические: открывание и игровой контроллер в библиотеку не добавлены.

У сундука, вентилятора и трёх существ сохранены исходные скелеты и
`AnimationPlayer`. Сундук содержит четыре анимации, остальные — по одной.
Их можно включить через `AnimationPlayer` импортированной сцены или игровой
скрипт. Для этих пяти объектов статические коллизии не создаются: подвижную
коллизию нужно связать с будущим игровым поведением. У декалей коллизий нет.

## Источники и повторная подготовка

`floors/platform_x_half.tscn` — половина `PlatformX` по плоскости X=0:
X от −2 до 0, Z от −2 до 2, размер 2×4. Масштаб текстуры, UV и исходная
точка привязки сохранены; коллизия повторяет только оставшуюся половину.
Для другой стороны можно повернуть сцену на 180° вокруг Y.
Исходник половинки: `models/platforms/Platform_X_Half.gltf` в папке ресурсов.
Его можно воспроизвести скриптом `tools/authoring/cut_platform_x_half.py`.
Производные модели перечислены в `derived_models.json` и сохраняются при
повторной подготовке библиотеки.

- Источники, текстуры, общие материалы и физические формы:
  `res://assets/models/modular_scifi_megakit/`.
- Полный список исходников: `library.json` в этой папке ресурсов.
- Список готовых объектов с размерами и анимациями: `library_index.json`
  рядом с этим документом.
- Лицензия: **CC0 1.0**, автор **Quaternius**. Подробности и оригинальный
  текст лицензии находятся в папке ресурсов.

Для повторной подготовки сначала выполни
`tools/authoring/import_modular_scifi_library.py` с путём к исходному ZIP,
дождись импорта ресурсов в Godot, затем запусти Godot с аргументами
`--headless --path <папка проекта> --script res://tools/authoring/prepare_modular_scifi_library.gd`.
Импортёр сохраняет существующие исходники, текстуры и настройки импорта;
подготовщик использует существующие общие материалы и ресурсы геометрии.
Автоматические LOD у glTF отключены для сохранения атласных UV на расстоянии.

Проверка библиотеки:
`--headless --path <папка проекта> --script res://tools/tests/modular_scifi_library_audit.gd`.
Проверяются загрузка сцен и зависимостей, размеры, совпадение коллизий с
поверхностями, ориентация потолков и сохранность всех восьми анимаций.

`selection.json` и `prepare_modular_scifi_kit.gd` относятся к старой выборке
из 34 моделей. Для полной библиотеки используй команды выше.
