# Запуск и сборка

## Зависимости

Проект настроен на Godot 4.7 с Forward+ и Jolt Physics. Используются поставляемые с репозиторием GodotSteam и Terrain3D. Совместимость нового редактора и экспортных шаблонов проверяйте перед обновлением; номер игры не зависит от номера движка.

Для штатного запуска на Windows нужны Git for Windows, Git LFS, подходящий Godot и Steam для кооператива. Blender нужен для редактирования исходников, но не для импорта готовых игровых моделей.

В `addons/godotsteam/win64/` должны присутствовать библиотеки debug/release и `steam_api64.dll`. Каталог `.godot/` создаётся редактором локально.

## Первый запуск

```powershell
git lfs pull
.\NorthernLab.cmd
```

Лаунчер подготавливает локальную копию редактора, проверяет экспортный шаблон, записывает сетевой отпечаток и пересобирает Windows Dev. Ярлык `NorthernLab.lnk` ведёт в лаунчер. Для обычной разработки открывайте `project.godot` в редакторе.

Новая игра начинается в `base_session.tscn`. В одиночном режиме нажмите `Esc` и подтвердите готовность к посадке. Для проверки сохранения используйте главное меню; F6 на сцене базы запускает временный сеанс.

## Сборка без запуска

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/northernlab_launcher.ps1 -BuildOnly
```

Результат: `build/windows-dev/NorthernLab.exe`. Для ручного экспорта сначала запишите идентичность исходников:

```powershell
& .\tools\.local\godotsteam-editor\godot.exe --headless --path . --script res://tools/write_build_identity.gd
```

Затем экспортируйте preset **Windows Dev** в редакторе. Лицензии подключённых моделей включаются через `export_presets.cfg`. Исходники Blender, документация и тестовые инструменты исключены из сборки.

## Иконка приложения

Иконка хранится в `assets/ui/application/northernlab.ico` и встраивается в Windows EXE при каждом экспорте. Файл содержит размеры от 16 до 256 пикселей. `northernlab.png` — копия кадра 256 × 256 для иконки проекта и окна Godot; при замене изображения обновляйте оба файла.

В Project Settings используются **Application → Config → Icon** и **Windows Native Icon**, в Windows Dev — **Application → Icon**. Ярлык лаунчера получает иконку из собранного EXE; до первой сборки используется ICO из проекта. Обычные ярлыки на EXE наследуют встроенную иконку автоматически.

## Типовые проблемы

| Симптом | Проверка |
| --- | --- |
| Вместо видео или EXR — короткий текстовый файл | Выполнить `git lfs pull`; убедиться, что это не LFS pointer |
| Ошибка Steamworks DLL, в том числе Windows Error 127 | Использовать локальную связку редактора и DLL, подготовленную лаунчером |
| Нет экспортного шаблона | Установить шаблон той же версии, что и выбранный редактор |
| Кооператив отклоняет подключение | Пересобрать оба клиента из одинаковых исходников с новым `network_build.cfg` |
| Steam Overlay не открывается | Запустить игровую сборку из Steam, а не окно редактора |

App ID 480 использует SpaceWar. Другу необходимо заранее запустить NorthernLab; для распространения и полноценного запуска по приглашению нужен собственный Steam-продукт. Подробности: [сеть](../technical/steam_networking.md).
