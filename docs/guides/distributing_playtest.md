# Версия для тестеров

Для передачи используется отдельный release-пресет **Windows Playtest**, Windows 10/11 x64. Одиночная игра и Steam-кооператив входят в один комплект. Пресет Windows Dev и разработческий лаунчер остаются для работы с проектом.

## Сборка

Нужны Python 3, локальный редактор GodotSteam, соответствующий ему release-шаблон Windows и Inno Setup 7. Пути инструментов можно передать через `--godot` и `--iscc`.

```powershell
python tools/build_playtest.py
```

Скрипт импортирует ресурсы, синхронизирует состав обоих пресетов, записывает идентификатор сети и экспортирует release. Затем проверяет встроенный пакет, новую игру, сохранения, управление, растения, лифт, восстановление тела и интерфейс. Отдельно запускает настоящий release EXE с проверкой главного меню и музыки. При ошибке упаковка прекращается. Для повторного экспорта существующий каталог кандидата сначала сохранить или переместить; готовую developer-сборку скрипт не заменяет.

После успешных проверок создаются:

- установщик в `build/distribution`, имя содержит ручную версию проекта и дату;
- portable ZIP с тем же комплектом;
- SHA-256 обоих архивов;
- каталог игры `build/windows-playtest` с `BUILD_INFO.json`, инструкцией и лицензиями.

`--package-only` повторяет упаковку уже проверенного EXE; контрольная сумма должна совпасть. При изменении исходников нужен полный экспорт. Версия из `project.godot` автоматически не повышается.

`--verify-existing` заново выполняет весь набор проверок готового кандидата без экспорта: использовать после исправления внешнего теста, когда игровые исходники и ресурсы кандидата не менялись. Проверка установки: `python tools/tests/playtest_installer_smoke.py <путь-к-Setup.exe>`. Она отказывается работать при уже зарегистрированной установке, ставит игру в отдельный каталог внутри `build`, сравнивает все хеши, запускает настоящий release EXE и удаляет тестовую установку с сохранением внешнего прогресса.

## Передача

Тестеру достаточно установщика либо portable ZIP. Не передавать репозиторий, `.godot`, `tools/.local`, исходники моделей или разработческий лаунчер. Установщик работает без администратора, создаёт ярлыки с правильным рабочим каталогом. Сохранения находятся в `saves/` рядом с `NorthernLab.exe`. Папка не входит в установщик и portable ZIP, а созданные во время игры файлы не удаляются установщиком. Перед ручным удалением всей папки игры сохраните копию `saves/`. Нужен каталог с разрешением на запись.

Обоим участникам кооператива передавать один комплект. Нужны запущенный Steam и два аккаунта; текущий App ID — 480. Проверка локальной сетевой логики не подтверждает приглашения и Steam P2P через интернет: перед общей рассылкой проверить создание лобби, приглашение, совместную высадку и продолжение у хоста на двух компьютерах. Установщик не подписан сертификатом разработчика; Windows может показать предупреждение о неизвестном издателе.

Инструкция тестеру хранится в `tools/distribution/start_here.txt`; оформление установки — `tools/distribution/playtest.iss`. Передавать найденные баги можно через F8, при недоступной отправке — локальным отчётом. Автоматические проверки не отправляют отзывы на сервер.

## Ограничения текущего прототипа

Ульи заменены неподвижными существами. Ветка побега с живыми ульями и финал ещё не готовы. Перенос внешней оболочки из сцены этажа 0 в общую сцену базы отложен: оболочка должна покрывать главный этаж и сохранять свои антенны.

## Проверенная поставка 23 октября 2026

Версия 1.00: установщик 386 168 090 байт, portable 446 197 113 байт. Экспортированный пакет прошёл 271 headless-проверку и 208 графических проверок; отдельно пройдены 235 проверок сборки, команд и стрельбы огнемёта, сетевой огнемёт — 28 проверок хоста и 11 клиента через ENet. Настоящий установленный release EXE проверен без окна и с графикой. Все 65 файлов комплекта сверены по SHA-256; ZIP также прошёл CRC-проверку. Тестовая установка удаляется, внешний маркер прогресса сохраняется. Проверка документации: 59 документов, ошибок нет. Эти результаты не заменяют внешнюю проверку Steam двумя аккаунтами.
