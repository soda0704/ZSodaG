# Звук и производительность — 25 сентября 2026

Настройки графики находятся в ESC → Настройки, ниже чувствительности мыши.
Есть низкий, средний и высокий профили и независимые параметры. Для слабого
компьютера начать с низкого профиля, затем поднять разрешение 3D с 70 до 85–100%.
Параметры сохраняются вместе с существующими настройками лаунчера.

Дальние горы: 16 мешей по 1089 вершин вместо 4225, без теней. Лес и камни
разбиты на 298 пространственных MultiMesh-групп по 128 м. Коллизии сохранены.
Дальность этих групп регулируется отдельно. Это оптимизация геометрии,
а не замена окружения панорамой. FPS на компьютере второго игрока не измерялся.

Все новые записи находятся в assets/audio/gameplay. Громкость и дальность
настраиваются в AudioStreamPlayer3D соответствующих сцен. Шаги выбираются
по metadata/footstep_surface у поверхности или её родителя: metal, snow,
floor; Terrain3D автоматически считается снегом. Частота зависит от движения,
а не от удержания клавиши бега. Металлом отмечены площадка, пандус, кабина
вертолёта и инспекционный мост этажа жизнеобеспечения.

Лифт: elevator_move.ogg — цикл с перекрытием краёв, loop включён в импорте;
при движении громкость плавно растёт, при остановке снижается, затем звук
останавливается. Движение дверей имеет отдельную запись. Переливание топлива
звучит после успешной передачи бензина, включая сетевое оповещение клиентов.
Звук щита реагирует на включение электричества. Голоса монстров пространственные,
с паузами, отключаются после смерти. Это локальные косметические звуки.

Дверные подсказки показывают только доступное действие; количество применений
монтировки не показывается ни у предмета, ни в журнале. Износ инструмента сохранён.

Проверки: tools/tests/door_arrival_regression.gd,
tools/tests/audio_graphics_regression.gd, tools/tests/snow_expansion_test.gd.
Для landscape_grounding_test.gd нужен графический рендерер: headless не читает
реальные GPU-трансформации MultiMesh. Проверены все 516 камней.
Отдельный прогон двух клиентов и оценка громкости на пользовательских наушниках
остаются ручной проверкой.
