# Версия игры

## Настройка

Текущая версия игры — **1.00**. Единственный источник — строка `application/config/version` в `project.godot`.

При выпуске обновления измените **Project → Project Settings → Application → Config → Version**, например на `1.01`. При необходимости включите Advanced Settings и найдите настройку через поиск. Значение хранится строкой, поэтому `1.00` не превращается в `1.0`.

Главное меню и статус сборки лаунчера читают эту настройку. Запуск, пересборка и обновление редактора её не увеличивают. Уже собранный EXE сохраняет свою версию; после изменения настройки соберите новый EXE.

## Разные виды версий

| Значение | Назначение |
| --- | --- |
| Версия игры | Номер обновления для игрока |
| Версия Godot | Совместимость редактора и экспортного шаблона |
| Сетевой протокол и отпечаток | Допуск к совместной сессии |
| Версия сохранения и раскладки | Чтение и миграция прогресса |

Изменение видимой версии не заменяет сетевую проверку и не требует сброса прогресса. Подробнее: [сохранения](save_system.md), [сеть](steam_networking.md).
