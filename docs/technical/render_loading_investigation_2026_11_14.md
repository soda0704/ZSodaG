# Vulkan / Direct3D 12 и загрузка ресурсов — 14.11.2026

## Исходный сбой

Пакет NorthernLab, Godot 4.7.2 Steam ed1daf0, Forward+, RTX 3060, Windows. В журнале export-menu-first-equipment.log ошибка `Uniforms were never supplied for set (4)` начинается после добавления Terrain3D в дерево в snow_exterior.finish_loading. Это временная связь, не установленный источник повреждённого набора ресурсов. В другом запуске export-menu-repeat-equipment.log возникла `Invalid Task ID` из WorkerThreadPool.wait_for_task_completion до первых проверок фонового видео. Стек GDScript для этой ошибки отсутствует.

Обе ошибки остаются неподтверждённо исправленными. Их отсутствие в последующих запусках не означает устранения причины. В игровом коде нет прямого вызова WorkerThreadPool: проверены scripts через поиск wait_for_task/add_task. Задачи может создавать ResourceLoader, расширение или рендерер.

## Сравнение драйверов

Один неизменённый пакет build/windows-dev/NorthernLab.exe, сборка 14.11.2026 16:02:20 +03:00; один editor-runtime, отдельные процессы, окно 1280×720, ограничение 60 FPS, Dummy audio. Это проверка корректности, не сравнение FPS. Для каждого драйвера выполнено два запуска с отдельным каталогом пользовательских данных. Фактический драйвер проверен по строке Using Device в журнале.

|---|---:|---:|
| Vulkan, два новых профиля | 90 | 0 |
| Direct3D 12, два новых профиля | 90 | 0 |
| Vulkan, два повторных запуска со старым userdata | 90 | 0 |

Журналы и сводки: tools/.local/render-diagnostics/baseline-results.json и reused-user-results.json. Последние два запуска не доказывают исправность любого кэша; они лишь не подтвердили гипотезу о проблеме именно прежнего userdata.

Смена Vulkan на Direct3D 12 не обоснована этими результатами: оба драйвера завершили те же проверки. Производительность не измерялась. В части запусков Direct3D 12 появлялось отдельное предупреждение Jolt о превышении количества jobs; его нельзя приписывать графическому API по одному совпадению.

## Изоляция

Внешний диагностический скрипт запускался на ресурсах готового пакета:

- 100 созданий/немедленных освобождений сцены выбора персонажа вне дерева: без ошибок.
- 12 быстрых и 12 обычных циклов главного меню и выбора персонажа: без ошибок.
- Три последовательные загрузки/выгрузки Terrain3D с обычной видимостью и три со скрытием до готовности карт: без ошибок.

Первый черновой тест Terrain3D пропустил родительский Node3D базы, необходимый local_blizzard._ready; его Nil-ошибка относится к неверному стенду. После восстановления иерархии обе серии завершились без ошибок. Скрытие Terrain3D не перенесено в игру: улучшение не доказано.

## Постоянная регрессия

tools/tests/render_loading_lifecycle_regression.gd выполняет три полных цикла через действующие GameMenu.start_standalone_flow и return_to_main_menu. Проверяет появление двух моделей, единственного локального игрока и метели, активную камеру, возврат в меню и удаление игровых узлов из дерева. Все записи направлены в изолированный каталог user://. Тест требует графического вывода, может запускаться с --main-pack готового EXE.

Сводка — tools/.local/render-diagnostics/lifecycle-results.json. Внешний runner сохраняет ошибки независимо от кода завершения: exit 0 не считается достаточным доказательством корректности. Полный путь теста передаётся через RENDER_TEST_SCRIPT; драйвер — --rendering-driver vulkan либо d3d12.

Оба драйвера завершили по три цикла и 18 утверждений без ошибок. Вместе с шестью полными проверками меню это 306 успешных утверждений; отдельные изоляционные прогоны в эту сумму не включены. Проверка компиляции скриптов render-diagnostics-integrity завершилась с SCRIPT INTEGRITY FAILURES 0 и errors []. Новая проверка использует тот же формат сохранений и публичные методы, производственные сцены и шейдеры в этом расследовании не менялись.

## Что осталось

Не менять игровой рендерер, не очищать пользовательские сохранения, не отключать всю фоновую загрузку и не добавлять таймеры для маскировки гонки. При новом воспроизведении сохранить полный журнал от старта процесса, графический драйвер, профиль, последовательность переходов и параметры графики. Следующее доказательное действие — минимальная сцена с тем же сбойным проходом; пока ни меню отдельно, ни Terrain3D отдельно исходную ошибку не воспроизвели.

Предупреждения Steam Input, Texture RID/ObjectDB и deprecated interpolation сохраняются; они не объявлены исправленными. Данные двух Steam-аккаунтов на разных ПК этой проверкой не покрыты.
