# Консоль разработчика

## Ввод

`~` / `ё` открывает консоль. `/help` показывает действующие команды. `Tab` дополняет текущий фрагмент, стрелки выбирают историю. Команды разделяются `;` и выполняются последовательно. Пример: `/god; /speed 3; /outside`.

Перед открытием наведите прицел на объект. Консоль запоминает путь и точку попадания; движение мыши не меняет цель. `/target` выводит путь, который можно передать целевой команде. Для другой цели закройте консоль и наведитесь заново.

## Команды

| Группа | Команды |
| --- | --- |
| Справка | `/help`, `/clear`, `/target`, `/status` |
| Перемещение | `/fly`, `/across`, `/speed 3`, `/speed reset`, `/where`, `/outside`, `/level 0` … `/level 5`, `/testroom` |
| Свободная камера | `/freecam`, `/freecam on`, `/freecam off`, `/freecam speed 5`, `/freecam speed reset` |
| Игрок | `/god`, `/heal`, `/flashlight` |
| Предметы | `/item TYPE [COUNT]`, `/weapon pistol|m4a1|kitchen_knife`, `/ammo`, `/fuel full|empty`, `/tape`, `/crowbar` |
| Объект под прицелом | `/open [ID]`, `/close [ID]`, `/kill [ID]` |
| Существа | `/spawn tail|slasher|smily|head|evolution [COUNT]`, `/despawn`, `/monsters reset|kill|status` |
| Прогресс | `/day 1` … `/day 999`, `/next day`, `/last day`, `/sleep`, `/wiring`, `/lightfault`, `/plant status`, `/plant water` |
| Видимость для тестирования | `/fullbright [on|off]` |
| Качество освещения | `/light_swap [basic|advanced]` |

Типы `/item`: `tape`, `crowbar`, `fuel_can`, `flashlight`, `battery`, `fuse`, `pistol`, `m4a1`, `kitchen_knife`, `pistol_ammo`, `rifle_magazine`. Предмет и тестовый монстр появляются в запомненной точке прицела. `/despawn` удаляет отладочно созданных существ, а не заменяет зачистку сюжетной встречи.

`/speed` — множитель 0,1–20 для отладочной ходьбы и полёта; `reset` возвращает обычное движение. `/across` позволяет проходить через стены и выбирать интерактивные объекты через препятствие в обычном радиусе. Смерть, сон и чужое удержание предмета по-прежнему ограничивают действия.

## Область действия

`/light_swap` переключает обычное и продвинутое освещение локально, без запроса хосту. Каждый запуск, включая первый на новом компьютере, начинается с продвинутого режима в пределах настроек графики. Явный выбор: `/light_swap basic` или `/light_swap advanced`. Обычный отключает GI, SSAO, объёмный туман и Glow, снижает качество теней только до закрытия игры. Состояние питания не меняется; выбор режима действует до конца запуска, включая смену сцен, и не записывается в настройки. Подробнее: [источники света](lighting_sources.md).

`/cave entry`, `/cave lair`, `/cave exit` переносят к точкам осмотра пещеры, сохранённым как Marker3D. `/level 5` возвращает к экспедиционному этажу. Эти серверные команды не меняют день, задачи и доступ лифта. Пещера тёмная: для осмотра выдайте `/flashlight` и включите его. Движение отдельной лебёдки пока не добавлено.

`/fullbright` включает или выключает светлый режим для тестирования без фонарика. `/fullbright on` отключает светотеневое затемнение через штатный Unshaded debug draw для мира и рук, убирает туман и влияние VoxelGI. `/fullbright off` возвращает авторское освещение, туман, GI и прежний режим рендеринга. Регулятор `/darkness` удалён: настройку художественной темноты выполняйте в сценах освещения.

Это локальные команды каждого участника; они не отправляются хосту, не включают генератор, не чинят щит и не меняют сохранение. Выход со сцены сбрасывает отладочный режим. Параметры читаемого фона редактируются в `assets/environments/debug_visibility.tres`, ссылка назначена у WorldLighting в Inspector. Команды доступны на базе после высадки.

`/freecam` отделяет камеру от тела для осмотра уровня и собственного персонажа. Закройте консоль: мышь поворачивает камеру, WASD перемещает в направлении взгляда, Space поднимает, Ctrl опускает, Shift ускоряет в 3 раза. Камера проходит сквозь стены. `/freecam speed 5` задаёт скорость в м/с (0,1–100), `reset` возвращает 5 м/с. Повторный `/freecam` или `/freecam off` возвращает вид от первого лица в текущее положение тела, без телепортации.

Режим камеры локальный и работает у каждого участника кооператива независимо. Движение, стрельба и взаимодействия персонажа блокируются, тело отображается целиком. Мир продолжает работать: камера не даёт бессмертия, при смерти или сне она возвращается в тело. Консоль и меню останавливают управление камерой. Прицел консоли использует положение свободной камеры; серверные ограничения расстояния до тела для целевых команд сохраняются. Перед включением закройте журнал и панель проводки.

Команды, которым нужна база, доступны после высадки. В салоне остаются команды игрока и предметов. Клиентское действие проверяет сервер; консоль не должна менять чужого персонажа локально.

Команды прогресса, лута и встречи могут попасть в checkpoint. Для экспериментов используйте F6 либо отдельное сохранение. `/monsters reset` не ремонтирует уже возникший сбой освещения.

## Подсказки и отладочная смена дня

Кликабельный список под выводом фильтруется по текущей команде. Tab перебирает дополнения; `/clear` (также `clear`) очищает вывод и историю, сохраняя список. В последовательности через `;` очистка удаляет и результаты предшествующих команд.

`/day N` проживает пропущенные дни растения по обычным правилам: полито в завершаемый день — одна стадия роста, первый пропущенный полив — необратимое увядание. Перемотка назад не отменяет рост или гибель и убирает дату полива из будущего. `/plant status` показывает состояние, `/plant water` отмечает отладочный полив сегодня без дистанционной проверки; засохшее растение эта команда не оживляет. `/status` показывает день, питание, топливо и общие флаги прогресса. Команды изменения состояния выполняет хост, но сама отладочная смена дня не пишет прогресс. `/next day` и `/last day` — переход на соседний день по тем же правилам, без записи. `/last day` означает предыдущий день, а не последний день кампании. Границы — 1–999.

`/sleep` мгновенно завершает одну ночь без проверки задач дня и согласия в кроватях. Используется обычный переход дня: рост/увядание растения, обслуживание базы, восстановление здоровья и радиации, пробуждение всех подключённых игроков у своих коек и утренний автосейв. Ручная запись истекает, появляется возможность на новый день. Неполученные сюжетные флаги команда не выдаёт. Запущенный ранее таймер сна отменяется, чтобы не произошло второй смены дня. После отладочной перемотки назад `/sleep` может записать новое утро поверх прежней ветки: будущие записи отбрасываются только после успешной записи нового файла. Обычный сон не может перезаписывать уже записанное утро.

Команда доступна после загрузки базы; все участники должны быть живы, выйти из транспорта и отпустить переносимое тело/тяжёлый предмет. В кооперативе запрос гостя, как и `/day`, выполняется на хосте и записывает общий мир только у него. При ошибке записи консоль сообщает, что утро наступило, но сейв не записан. В F6 запись остаётся отключённой; консоль явно сообщает об этом. Обычный сон по-прежнему требует выполнение задач и сон всех подключённых игроков.

Проверка: `tools/tests/console_sleep_regression.gd` — относительные дни без записи, утренний сейв, восстановление игрока, рост растения, отмена старого таймера, ошибка записи и F6. `python tools/tests/run_expedition_multiplayer.py` также проверяет `/sleep` из консоли гостя с общей записью у хоста.


### Новые существа

`/spawn head` создаёт быструю голову; `/spawn evolution 2` — две Эволюции в точке прицела. Для второго типа также принимается `involuntary_evolution`, для головы — `голова`. `/monsters status` выводит текущее состояние активных существ, здоровье, цель и навигационную диагностику. `/despawn` убирает отладочные экземпляры. `reset` и `kill` относятся к исходной сюжетной тройке; новые модели сами по себе не меняют состав встречи пятого дня. Массовый спавн остаётся стресс-тестом.
