# Консоль и перетаскивание предметов

Наведитесь на объект и откройте консоль клавишей `~` / `ё`. Верхняя строка
показывает ID (полный путь узла) и запомненную точку прицела. Пока консоль открыта,
цель не меняется от движения мыши. Для смены цели закройте консоль и наведитесь снова.
`/target` выводит ID в журнал, откуда его можно скопировать. Удалённая цель
возвращает сообщение об отсутствии объекта.

| Команда | Действие |
| --- | --- |
| `/open`, `/close` | Открыть/закрыть выбранный гараж одному или дверь без монтировки и питания |
| `/open ID`, `/close ID` | То же по скопированному ID |
| `/kill [ID]` | Убить только выбранного монстра |
| `/item crowbar` | Создать монтировку в точке прицела |
| `/item fuel_can 3` | Создать три канистры в точке прицела |
| `/spawn tail 2` | Создать двух хвостатых в точке прицела |
| `/tape`, `/crowbar` | Выдать соответствующий инструмент в инвентарь отдельно |
| `/tools` | Прежняя выдача обоих инструментов |
| `/speed 3` | Умножить скорость ходьбы, бега и полёта на 3 для вызывающего игрока |
| `/speed reset` | Вернуть обычную скорость; числовой диапазон `/speed`: 0.1–20 |
| `/fly`, `/across` | Полёт / полёт сквозь стены; Shift сохраняет ускорение полёта |

Предметы: `tape`, `crowbar`, `fuel_can`, `flashlight`, `battery`, `fuse`,
`pistol`, `m4a1`, `kitchen_knife`, `pistol_ammo`, `rifle_magazine`.
Монстры: `tail`, `slasher`, `smily`. Если луч не встретил поверхность, используется
точка в трёх метрах перед камерой. При группе первый объект появляется в выбранной
точке (с небольшим подъёмом над поверхностью), остальные — рядом. До 100 предметов
или 1000 монстров за одну команду. `/despawn` убирает тестовых монстров.

У открытого гаража можно навестись на оранжевую рукоять, затем выполнить `/close`.
Команды обычных дверей принудительно сохраняют выбранное состояние, поэтому
автоматика не отменяет результат на следующем кадре. Состояния дверей и гаража
входят в checkpoint обычного сеанса, как прочие изменения прогресса.

## Быстрый ввод

- `/` уже заполнен при первом открытии и после отправки.
- Клик по команде в верхнем списке вставляет её, но не выполняет. Enter выполняет.
- Повторный клик заменяет команду в текущем сегменте строки.
- После `;` клик заполняет новый сегмент: `/ammo; /fly`. Другие сегменты сохраняются.
- Tab дополняет текущую команду и её аргументы из списка. Повторный Tab выбирает
  следующий подходящий вариант. Например, `/f` перебирает `/fly`, `/flashlight`,
  `/fuel full`, `/fuel empty`.
- Команды через `;` выполняются слева направо. Во втором сегменте `/` необязателен.
- Стрелки вверх/вниз перебирают историю целых строк.

## Перетаскивание

Короткое E на физическом подбираемом предмете сохраняет подбор. Удержание от
0,25 секунды притягивает его перед взглядом; предмет остаётся физическим и
сталкивается со стенами. Отпускание E бросает предмет. Снаряжение в руках
не заменяется. Сценический декор и закреплённые объекты не перетаскиваются.

Движение предмета рассчитывает сервер и передаёт через существующую синхронизацию
WorldItemPickup. Второй игрок не может одновременно схватить или подобрать
удерживаемый предмет. Открытие меню/консоли, смерть, посадка, выход игрока или
потеря управляющих пакетов освобождают предмет. Груз лифта можно снять с его
платформы и переносить тем же способом.

UI консоли находится в `scenes/ui/developer_console.tscn`, параметры удержания —
в компоненте `ItemDrag` сцены игрока, доступны в Inspector.

В `/across` прицел игнорирует стены при выборе ближайшего интерактивного объекта,
а сервер допускает его подбор через препятствие в обычном радиусе взаимодействия.
Смерть, сон, посадка и чужое удержание предмета по-прежнему блокируют подбор.
После выключения режима возвращаются обычный луч и проверка видимости.

Возрождение выбирает существующие точки сцены: при выключенном генераторе —
маркер игрока в вертолёте, при включённом — точку в комнате. Позиции не задаются
новыми координатами в коде.

  множитель скорости и сброс, репликация, Shift в полёте и реальный подбор через

  выбранного монстра. Запускать отдельно от гаражного теста: тот же порт 29474.
