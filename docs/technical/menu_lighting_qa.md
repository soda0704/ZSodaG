# Проверка меню и освещения

Проверка 15.10.2026: главное меню → выбор персонажа → одиночный салон → явная готовность → высадка → база → ESC → настройки → сохранение → главное меню → продолжение. Дополнительно проверены лобби хоста/гостя, журнал, модальные окна, переключение камер, этажи, штатное/аварийное питание, фонарик и локальный fullbright.

## Оптимизация без изменения качества

Сохранены текущие пресеты, масштаб, MSAA, геометрия, энергии/радиусы источников, бюджеты света и все меню. Удалён неиспользуемый steam_status_label, создававшийся без родителя и никогда не отображавшийся.

Неизменные настройки больше не обходят всю сцену. Изменение только FPS не трогает Environment и не перестраивает глобальные бюджеты. При калибровке пропускаются неизменные настройки SSAO/тумана/GI/теней. Неизменные переназначения управления не записываются заново.

Геометрия и лампы модели рук отслеживаются через добавление/удаление узлов вместо двух поисков по скелету каждый кадр. Проверено динамическое добавление, отсоединение и возвращение оборудования. Для освещения рук используются те же активные источники, но обходится список резидентных ламп. Свойства Environment выбираются один раз при смене исходного ресурса. Отладочные viewport не ищутся каждый кадр в штатном режиме.

Контроль стоимости CPU на реальной базе: обход сцены quality._visit(root) — 13.865 мс на вызов (100 повторов); пропуск неизменного apply — 0.00754 мс. Два поиска по модели — 54.973 мкс на пару; чтение актуальных списков — 0.173 мкс (1000 повторов, 29 геометрий, 4 лампы). Это изолированная стоимость исключённых операций, а не прирост FPS всей игры. Замер: Vulkan Forward+, RTX 3060, 2560×1440, текущий High; VSync/лимит выключены. Графические бюджеты в обоих вариантах одинаковы.

Контрольные кадры базы до/после в 960×540: средняя абсолютная разница RGB (шкала 0…255) — гараж 0.0162, центральный зал 0.0158, уровень −2 0.0085, улица 0.1532. Кадры снимаются в разных запусках с временными эффектами, поэтому это проверка отсутствия крупного визуального изменения при оптимизации, а не попиксельное тождество. Сохраняются в tools/.local/menu-light-qa-before и tools/.local/world-lighting-review. Салон намеренно изменился после исправления положения ламп; это отдельное исправление освещения, а не снижение качества.

## Выполненные проверки

Нативный Vulkan: menu_lifecycle_regression, menu_integration_regression, menu_quality_regression, menu_dialog_layout_regression, journal_presentation_regression, character_view_isolation_regression, debug_visibility_regression, world_lighting_regression, menu_lighting_chain_regression, tester_feedback_regression.

Салон: cabin_lighting_regression — до переноса ламп 6 провалов из 12 условий; после переноса 12 проверок без провалов, включая реальные лучи через корпус и попадание пола в конус света.

Без графики: expedition_menu_regression, expedition_save_slots_regression, expedition_resume_regression, audio_graphics_regression, menu_font_storage_regression, door_arrival_regression.

Готовая сборка: menu_export_render_regression проверил 43 условия на упакованных ресурсах и сохранил снимки меню; menu_lighting_chain_regression прошёл всю цепочку с высадкой и восстановлением света из сохранения. Обычный запуск NorthernLab.exe завершился с кодом 0, без ERROR/SCRIPT ERROR. Для запуска тестов пакета Terrain3D DLL должна находиться рядом с тестовым редактором; отсутствие библиотеки там не означает её отсутствие в самой сборке.

Два настоящих локальных ENet-процесса: run_expedition_multiplayer.py — хост 8 проверок, гость 15, без провалов. Проверены позднее подключение, снимок состояния, прогресс, инвентарь и запрет гостю писать чужую экспедицию.

Для всех проверок использованы отдельные APPDATA/LOCALAPPDATA и тестовые пути сохранений. Личные настройки и прогресс не изменялись. Тест обратной связи отключает внешний получатель; 45 проверок без провалов. Его намеренно некорректный путь создаёт ожидаемое сообщение Godot о невозможности создать папку; это проверка обработки отказа, а не ошибка обычного запуска.

Полная проверка приглашений Steam требует двух аккаунтов; локальный ENet и проверки лобби не подтверждают работу внешнего оверлея. Тесты не являются гарантией отсутствия всех ошибок на других видеокартах, в HDR или при длительной сетевой игре.

В обычном запуске Steam с тестовым App ID 480 отклонил Input Action Manifest. В коде предусмотрен ввод через Godot при таком отказе; нативные Steam Input action sets не считаются проверенными. В цепочке базы также остаются предупреждения движка о deprecated интерполяции Terrain3D и чтении геометрии при запекании навигации; они не вызвали провалов теста. Этот проход не меняет Terrain3D, алгоритм запекания навигации или настройки Steam приложения.
