# Сохранения и совместимость

## Владение и файлы

Прогресс записывает и загружает только хост. Клиент получает сетевое состояние и не подменяет его локальным файлом.

| Файл | Назначение |
| --- | --- |
| `user://base_gameplay_state.cfg` | Одиночная экспедиция |
| `user://base_gameplay_state_coop.cfg` | Кооперативная экспедиция |
| `northern_lab/testing/base_save_path` | Проектная настройка отдельного пути для теста |

`user://` относится к каталогу пользовательских данных Godot, а не к папке репозитория. Соло и кооператив не объединяют сохранения автоматически. Основная реализация: `scripts/gameplay/base/base_gameplay_controller.gd`; инвентарь участников собирает `scripts/network/base_session_controller.gd`.

## Содержимое

Сохраняются день, питание и топливо, стадия ключа, обслуживание, здоровье и тела сюжетных монстров, состояние медицинского переноса, инвентарь участников, оставленные предметы, снегоход и открытые ворота. Предметы внутри кабины лифта записываются относительно кабины.

Текущие подтверждения сна, действие перезарядки, посадка за руль, здоровье и радиация игрока не служат точкой продолжения. Следы снега, следы пуль и история локальных звуков не сохраняются. При сохранении во время переноски тело восстанавливается свободным рядом с последним положением носильщика.

Изменения важных состояний инициируют запись; для расхода и физического положения предусмотрено периодическое сохранение. Принудительное завершение процесса может потерять последние изменения после записи.

## Продолжение и миграции

«Продолжить» доступно для совместимого файла. Новая игра и удаление прогресса требуют подтверждения в меню. Продолжение использует отдельный сценарий сессии и восстановленное состояние; не следует вручную создавать стартовый лут поверх сохранённого.

Текущий формат имеет `SAVE_VERSION = 1`. Дополнительные версии раскладки инвентаря позволяют добавить начальные припасы старым сохранениям однократно. `campaign_layout_version` переносит прежнюю объединённую встречу на отдельные дни. Старые пути невидимых медицинских коек переводятся на фактические койки медкомнаты.

Версия игры, версия формата сохранения и сетевой отпечаток имеют разные назначения. Увеличение `application/config/version` не должно сбрасывать экспедицию.

## Правила изменения

Добавляя сохраняемое поле, определите значение по умолчанию для старого файла. Меняя путь узла, проверьте сохранённые NodePath. Миграция не должна повторно создавать собранные предметы или лечить повреждённых существ.

F6 на базе отключает обычную запись прогресса. Перед запуском теста убедитесь, что он назначает отдельный путь: не используйте игровые файлы как тестовую фикстуру.

Проверки: `day_split_checkpoint_regression.gd`, `medical_corpse_recovery_regression.gd`, `snowmobile_model_recovery_regression.gd` в `tools/tests/`. Ручная проверка — продолжение обоих режимов, отключение участника с предметом и загрузка после смены дня.
