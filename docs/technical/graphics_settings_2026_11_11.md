# Независимые параметры графики и пресеты — 11.11.2026

## Поведение

Убраны общий Basic/Advanced override, `/light_swap`, его подсказки и кнопка консоли. Осталась одна схема света. `GraphicsQuality` применяет сохранённые параметры независимо; GI, SSAO, Glow и тени больше не выключаются общим флагом.

GI имеет значения 0/1/2/3: Off / Low half-resolution / High half-resolution / High full-resolution. Off освобождает данные VoxelGI, сохраняя прямой свет, тени, SSAO и Glow. `GIQuality` включён в условия обновления существующих узлов. Новые узлы наследуют текущие значения через отложенный `apply_node()`.

Питание и fullbright остаются отдельными ограничителями. Во время аварии GI не отображается даже при выбранном High. Восстановление питания возвращает выбранное качество, включая явное Off. Причина белёсого вклада аварийного VoxelGI из предыдущего отчёта не установлена; исключение GI из аварии сохранено.

## Что исправлено

- Значения Graphics приводятся к допустимым диапазонам и типам при загрузке и применении. Интерфейс показывает те же числа, которые получает рендеринг. Неверный тип целого Graphics также восстанавливается в defaults.
- Сохранённый пользовательский лимит FPS, отсутствующий среди готовых вариантов, показывается своим числом вместо «Без ограничения».
- Сброс качества отменяет ожидающий автоподбор, чтобы тот позднее не заменял явный выбор пользователя.
- В режиме развёрнутого окна недоступен выбор разрешения: используется размер рабочего стола. В оконном и полноэкранном режимах выбор доступен.
- HDR применяется после выбора монитора и режима окна, в том числе если сами Graphics не менялись. Недоступность HDR определяется текущим дисплеем. Подтверждение HDR-картинки требует подходящего дисплея.
- В Environment карты разрешён Glow с прежними консервативными значениями: intensity 0,12, HDR threshold 1,7. Ранее выключенный авторский флаг делал пользовательское включение неэффективным. Кабина и UI-превью сохраняют собственные Environment.
- Убраны из текущего меню и пресетов «Объёмный туман» и «Дальность деревьев и камней»: активная карта не использует эти объекты/объёмный туман. Метель — самостоятельный пространственный эффект. Совместимость старых данных FogQuality/VegetationDistance и сторонних сцен сохранена в обработчике.
- У параметров добавлены пояснения, включая зависимость силы размытия от его включения, действие LOD только на подготовленные модели и действие GI при штатном питании.
- Журнал консоли сохраняет свою область до первого сообщения и после очистки. Поэтому кнопки остаются под курсором между быстрыми кликами. Проверяется неизменность их позиции, выполнение обоих кликов и сохранение фокуса текстового/числового ввода.

## Реальные получатели параметров

| Параметр | Что меняется |
| --- | --- |
| Scale | `Viewport.scaling_3d_scale`, интерфейс сохраняет нативное разрешение |
| MSAA / FXAA | Главный Viewport и отдельный ViewmodelViewport |
| FPS | `Engine.max_fps`; VSync дополнительно ограничивает частотой дисплея |
| ShadowQuality | Атласы солнца и локальных ламп, фильтры теней |
| ShadowDistance | `WorldLighting.quality_shadow_distance`, затем реальная дальность теней солнца с учётом интерьера |
| AOQuality | `Environment.ssao_enabled` и глобальное качество SSAO |
| GIQuality | Активность/резидентность VoxelGI, разрешение и качество GI, режим комнатной sky isolation |
| Bloom | `Environment.glow_enabled` на камере; реальный ореол у ярких поверхностей |
| LOD | `Viewport.mesh_lod_threshold`; эффект зависит от наличия LOD у конкретного Mesh |
| DecalDistance | Distance Fade существующих и вновь создаваемых Decal, включая снежные следы |
| TrackCount | `SnowTracks.max_marks`, удаление самых старых отпечатков при превышении |
| MotionBlur / Strength | Сигнал существующему CameraPostProcess и параметры выборок шейдера |
| Brightness / Gamma | Калибровка Environment текущей камеры, без перезаписи исходного ресурса |
| HDR / HDRWhite | Запрос HDR-вывода и опорная яркость поддерживаемого дисплея |
| ShowFPS | Настоящий FPSCounter, включая остановку обработки при выключении |

## Границы проверки

Наличие актуального значения у рендерера не означает видимое изменение каждого объекта: LOD требует подготовленных уровней детализации, Glow — достаточно яркого материала, GI — штатного питания. Кадры трёх пресетов сняты с одной камерой в одной сцене; их время GPU не характеризует всю игру. HDR и смена нескольких физических мониторов требуют соответствующего оборудования. Два сетевых клиента в этом этапе не запускались; настройки остаются локальными.

В логах сохраняются ранее зафиксированные предупреждения Steam Input Manifest и семи Texture RID при выходе; контрольное завершение EXE также сообщает о двух ObjectDB instances. Они не выдаются за исправленные в этом этапе.
