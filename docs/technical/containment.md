# Уровень 3: биосдерживание

На третьем игровом дне журнал предлагает обследовать уровень 2. Посещение
его внутренней части открывает уровень 3 в лифте. Там находятся три существа
из предоставленных архивов: The Monster, Slasher и Smily.

Противники преследуют живых игроков по навигационной сетке, атакуют с замахом
и проверкой стены между игроком и противником. Здоровье: 120 / 90 / 75.
Работают попадания пистолета, M4A1 и ножа. Урон и ИИ считает сервер.

После гибели всех трёх начинается сбой освещения. Главный щит на уровне 0
нужно выключить, затем включить. Только после этого можно завершить день.
Здоровье противников, этапы обследования и сброс щита входят в сохранение базы.

Анимации импортированы из архивов: каждый содержит один общий клип, у The Monster
это длинная лента. Из неё выделены idle (0–2.8 с), движение (65–66 с), атака
(235–236 с) и смерть (239.5–241 с, последний кадр фиксируется). Root motion
живого существа отключён, положением управляет ИИ. Smily уменьшен до 1.15 м.
После смерти используются RigidBody3D с коллизией тела и контактными точками
головы/конечностей. Это упрощённая физика цельного тела, не покостный ragdoll.
Поза и положение сохраняются; восстановленные неподвижные тела не симулируются
повторно. В старых сейвах, где координат не было, восстановить место гибели нельзя.
Для повторного теста используйте `/monsters reset`.
Калибровка размера рассчитана по скелетной позе и одинаковая на графическом клиенте
и headless-сервере. Навигация пока запекается при входе на карту.

Проверка: `godot --headless --path . --script tools/tests/containment_test.gd`.
Тест использует отдельное сохранение, не изменяя игровой прогресс пользователя.
Атрибуция моделей: `assets/monsters/ATTRIBUTION.md` (копируется рядом с EXE).

## Консоль разработчика

`~` / `ё` открывает консоль, Esc закрывает. Справка показана сразу, `/help`
повторяет её. История команд — стрелки вверх/вниз. Доступ к изменению мира
есть только у хоста/одиночного игрока; команды не выполняют произвольный код.

- `/fly`: полёт с коллизиями. WASD + мышь, Space вверх, Ctrl вниз, Shift быстрее.
- `/across`: полёт сквозь стены; повторный вызов возвращает обычное движение.
- `/god`, `/heal`: бессмертие, восстановление здоровья.
- `/level 0..4`, `/where`: телепорт к входу и координаты.
- `/day 1..4`: смена дня и включение питания; изменяет сохранение!
- `/weapon pistol|m4a1|kitchen_knife`, `/ammo`: экипировка для теста.
- `/monsters reset|kill`: сброс встречи или убийство всех существ.
- `/lightfault`: включить сбой света без боя. `/clear`: очистить журнал консоли.

Быстрый тест: `/day 3`, `/level 3`, `/weapon m4a1`, `/ammo`, `/monsters reset`.
Полёт и бессмертие не записываются в сейв. Изменения квеста, монстров и инвентаря
сохраняются обычной системой: для экспериментов используйте тестовый прогресс.
