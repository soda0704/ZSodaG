# Пользовательские настройки

## Хранение

`GameMenu` и Windows-лаунчер используют `%LOCALAPPDATA%/NorthernLab/launcher_settings.json`. При отсутствии LOCALAPPDATA используется `user://launcher_settings.json`. Переназначения управления хранятся отдельно в `user://controls.cfg`.

Настройки не являются прогрессом экспедиции. Менять их можно из главного меню и через `Esc`. Лаунчер сохраняет вложенные параметры Graphics при изменении параметров окна.

## Экран и графика

Режим окна, разрешение, монитор и VSync применяет `scripts/ui/game_menu.gd`. Графику обслуживает `graphics_quality.gd`; общий интерфейс четырёх категорий — `scripts/ui/settings_menu.gd`. Оформление и оболочка сохранены в `scenes/ui/menu_theme.tres` и `menu_shell.tscn`.

Параметры и переназначения клавиш редактируются в черновике. «Применить» сохраняет и применяет их; при выходе с изменениями предлагаются применение, отмена изменений или возврат к редактированию. «По умолчанию» сбрасывает только открытую категорию. Список качества прокручивается внутри неизменной области экрана. Числовое значение меняется перетаскиванием с ЛКМ либо стрелками; простой клик по числу его не увеличивает.

Доступны масштаб 3D, MSAA/FXAA, лимит FPS, SSAO, SSIL, SSR, Glow, туман, тени, LOD, дальность растительности/декалей, количество следов, яркость и гамма. Яркость относится к общему Environment; вход в комнату не включает отдельный световой купол.

Настройка качества только ограничивает авторские тени, а не создаёт новые источники. Растительность использует metadata `exterior_chunk`/`boundary_detail`. Количество снежных следов переопределяет `SnowTracks.max_marks`: значение сцены 512 может быть ограничено настройкой Graphics (по умолчанию 128).

HDR включается только при поддержке дисплея. `HDRWhite` задаёт опорную яркость. Само наличие переключателя не подтверждает рабочий HDR-вывод; это проверяется на совместимом дисплее. UI-SubViewport журнала исключён из мировых эффектов.

## Звук и управление

Громкости Master, Music, Effects, Weapons, Vehicles, Machinery, Ambience и Breathing независимы; RoomReverb регулирует долю комнатного эффекта. См. [звук](audio_mix.md).

Доступны чувствительность мыши и настройки действий в `ControlSettings`. Контроллер использует Steam Input или резервную раскладку Godot. Пользовательская раскладка Steam не гарантирует совпадение её значков с подсказками игры.

## Проверка

`menu_integration_regression.gd`, `audio_graphics_regression.gd`, `audio_balance_startup_regression.gd`, `journal_presentation_regression.gd`. Для проверки геометрии прокрутки и кадров меню запустить первый тест графически с `-- --capture`. Дополнительно перезапустить игру, проверить сохранение настроек лаунчера, разные мониторы, HDR и относительный уровень категорий.
