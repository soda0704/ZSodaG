# Оптимизация и порядок ресурсов

## Применённые решения

Для 32 текстур моделей включены GPU-сжатие и mipmaps через штатный импорт Godot. Разрешение, пути, UID и исходные изображения сохранены. Изменение импорта не уменьшает геометрию и не заменяет материалы.

Chinook использует одну текстуру для двух одинаковых карт Interior/InteriorAlpha. Исходные изображения имеют одинаковый SHA-256. Второй файл оставлен как исходник и исключён из сборки; UV и правила прозрачности модели сохраняются.

Снежные следы проверяют fade только у старой части упорядоченного списка. Контактные маркеры снегохода получаются один раз на серию отпечатков. Частота физики, шаг, срок жизни и правила контакта не менялись.

Экспорт исключает авторские Blender-файлы, `.blend1`, исходники оружия, документацию, инструменты и запросы генерации изображений. Нужные ресурсы и лицензионные файлы остаются в сборке.

## Инвентаризация

```powershell
python tools/audit_project_assets.py --output tools/.local/asset-audit.json
```

Нужен Python 3.11+. Инструмент использует стандартную библиотеку и не изменяет assets. Отчёт содержит размер по расширениям, крупнейшие файлы, точные хеш-дубликаты и PNG выше 4K.

В контрольной инвентаризации исходные assets занимали около 1252 MiB, кандидаты-дубликаты — около 196 MiB. Это объём исходников на диске, не видеопамять игры. Дубликаты нельзя удалять по хешу без проверки GLB, `.res`, редакторских зависимостей и динамических загрузок.

Выбранные GPU-импорты занимали около 202 MiB; расчёт исходных размеров как RGBA без mipmaps даёт около 1016 MiB. Сравнение форматов не является измерением экономии всей сцены: не все карты загружены одновременно и исходные форматы различались.

## Профилирование

Измеряйте отдельно загрузку, первые кадры и прогретую сцену. Фиксируйте разрешение, масштаб 3D, ракурс, MSAA, SSIL/SSR, лимит FPS, VSync и аппаратную конфигурацию. Контрольный замер: [производительность окружения](performance_baseline.md).

Не отключайте серверную физику этажа по камере хоста: там может находиться второй участник. Не уменьшайте визуальную сложность без подтверждённой стоимости. Изменение качества должно сохранять проходимость, взаимодействия и читаемость.

## Проверка

После изменения импорта — импорт редактором, `project_resource_audit.gd`, профильные проверки и осмотр материалов. После изменения экспортных фильтров — сборка и запуск экспортированного EXE. Отсутствие ошибок зависимости не подтверждает качество GPU-сжатия, FPS или работу двух клиентов.

Рабочие логи, диагностические сцены и тестовые сборки храните в `tools/.local`, а не в игровых каталогах.
